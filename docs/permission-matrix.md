# Android Permission Matrix & Security Declaration

This document establishes the exhaustive matrix of all Android permissions utilized by **TakeBack**, including protection levels, technical justifications, user-facing rationales, and graceful degradation strategies.

---

| Permission Identifier | Protection Level | Declared in Manifest | Runtime / System Request Method | Technical Justification | User-Facing Explanation | Fallback if Denied |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `android.permission.PACKAGE_USAGE_STATS` | AppOp / Special Access | Yes | `Settings.ACTION_USAGE_ACCESS_SETTINGS` | Required to query `UsageStatsManager` for cumulative app screen time and hourly usage. | "Needed to measure how much time you spend in each app and enforce daily limits." | Screen-time analytics disabled; app limits rely on Accessibility foreground time tracking. |
| `android.permission.SYSTEM_ALERT_WINDOW` | Special Access | Yes | `Settings.ACTION_MANAGE_OVERLAY_PERMISSION` | Required to display instant, polite `BlockShield` over restricted apps without task switching delays. | "Allows TakeBack to show a calm blocking screen when a restricted app is opened." | System uses standard task-switching `BlockShieldActivity` launched into Home stack. |
| `android.permission.BIND_ACCESSIBILITY_SERVICE` | Signature / Special | Yes | `Settings.ACTION_ACCESSIBILITY_SETTINGS` | Required for instantaneous (<30ms) app switch detection, browser URL address extraction, and Shorts filtering. | "Enables instant app blocking, website URL filtering in browsers, and selective Shorts blocking." | App limits fall back to UsageStats polling; website filtering falls back to local DNS VPN. |
| `android.permission.BIND_NOTIFICATION_LISTENER_SERVICE` | Signature / Special | Yes | `Settings.ACTION_NOTIFICATION_LISTENER_SETTINGS` | Required to suppress distracting notifications from restricted apps during active focus sessions. | "Allows TakeBack to silence notifications from distracting apps during work or study sessions." | Notification blocking disabled; restrictions only apply when opening apps. |

| `android.permission.USE_EXACT_ALARM` | Normal (API 33+) | Yes | Manifest | Exclusively used for Strict Alarm clock functionality (`AlarmManager.setAlarmClock()`). | "Guarantees your morning strict alarm rings punctually even when the phone is in deep sleep." | Standard alarms used. |
| `android.permission.ACCESS_FINE_LOCATION` | Runtime | No (Intentionally Excluded) | N/A (Decoupled Snapshot Engine) | Deliberately excluded to maintain zero battery drain and complete user privacy. Geofence evaluation is decoupled in `CentralRestrictionEngine`. | N/A | Zero continuous location tracking; battery usage reduced to near-zero. |
| `android.permission.ACCESS_BACKGROUND_LOCATION` | Runtime (API 29+) | No (Intentionally Excluded) | N/A (Decoupled Snapshot Engine) | Deliberately excluded from manifest to protect user privacy. | N/A | No always-on GPS tracking. |
| `android.permission.REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | Normal | Yes | `Settings.ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | Prevents Android OS and OEM power managers from killing the background monitoring service. | "Prevents your phone from terminating TakeBack's protection while you are working." | App remains functional, but restrictions may suffer delays on aggressive OEM devices. |

| `android.permission.FOREGROUND_SERVICE_MEDIA_PLAYBACK` | Normal (API 34+) | Yes | Auto-granted at install | Specific FGS type for Module I (Focus Sounds ambient audio player). | "Enables background playback of rain, ocean, and white noise sounds." | Focus sounds stop when screen turns off. |
| `android.permission.FOREGROUND_SERVICE_SPECIAL_USE` | Normal (API 34+) | Yes | Auto-granted at install | Specific FGS type for real-time restriction enforcement and anti-distraction protection. | "Maintains continuous distraction protection during scheduled focus windows." | Subject to OS background restrictions. |
| `android.permission.VIBRATE` | Normal | Yes | Auto-granted at install | Haptic feedback for Strict Alarm challenges and block alerts. | "Provides haptic feedback for alarms and challenge interactions." | No vibration alerts. |
| `android.permission.WAKE_LOCK` | Normal | Yes | Auto-granted at install | Keeps CPU awake transiently during alarm ringing and strict mode countdowns. | "Ensures the alarm sounds continuously until the challenge is solved." | Audio may stutter if device enters deep sleep during alarm. |

## 2. Policy Compliance & Ethical Declarations
1. **Accessibility API Disclosure:** In compliance with Google Play Developer Program Policies, TakeBack prominently displays an in-app disclosure modal before directing users to Accessibility settings. The modal explicitly details:
   - *What data is accessed:* Current window package name and browser address bar text.
   - *What data is NOT accessed:* No passwords, no credit cards, no messaging chats, no personal data.
   - *Where data is processed:* 100% on-device inside the local restriction engine; zero network transmission.
2. **VpnService Disclosure:** For local DNS website blocking, TakeBack uses `android.net.VpnService` exclusively as an on-device packet filter resolving domain queries to `127.0.0.1`. No traffic is routed through remote proxies or VPN servers.
